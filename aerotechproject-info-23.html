// Overview

Abstract

This project is a homemade 4-wheel RC car controlled wirelessly using two ESP32 boards and Wi-Fi. The controller ESP32 reads joystick input and transmits data via UDP to the car ESP32, which drives four DC motors through an L298N dual H-bridge motor driver. The system features differential steering, a wireless fail-safe, and a dedicated Wi-Fi network for control.

// Goals

Objective

  • Build a functional Wi-Fi controlled 4-wheel drive RC car from scratch
  • Implement low-latency UDP communication between two ESP32 boards
  • Control four DC motors via an L298N dual H-bridge motor driver
  • Use a joystick module for intuitive handheld control
  • Implement differential steering for left and right turning
  • Add a wireless fail-safe that stops the motors on signal loss

// Transmitter

ESP32 Wireless Controller

The first ESP32 is the handheld transmitter. It reads the joystick position continuously and sends control packets to the car ESP32 over UDP through a dedicated Wi-Fi access point. VRX controls left/right steering, VRY controls forward/backward movement, and SW is the joystick push button.

// Car ESP32

ESP32 Car Receiver

The second ESP32 is mounted inside the RC car chassis. It connects to the RC_CAR Wi-Fi network, receives UDP control packets from the controller, decodes the joystick values, calculates the required motor speeds and directions, and drives the L298N. If no packet is received within approximately 300 ms, it stops all motors automatically.


  • Connects to the RC_CAR Wi-Fi access point created by the controller
  • Listens for incoming UDP control packets continuously
  • Parses joystick X and Y values from each received packet
  • Calculates left and right motor speeds using differential steering logic
  • Outputs PWM speed and direction signals to the L298N motor driver
  • Activates the wireless fail-safe if no packet is received for ~300 ms
// Motor Driver

L298N Motor Driver

The L298N is a dual H-bridge motor driver that controls the left and right motor groups independently. The ESP32 sends PWM signals to ENA and ENB for speed control, and digital HIGH/LOW signals to IN1–IN4 for direction control.

The two motors on the left side are wired in parallel and treated as a single group. The same applies to the right side. This provides 4-wheel drive with independent left/right speed control for differential steering.

Control System

The joystick provides two analog axes. The system uses differential steering — the left and right motor groups are driven at different speeds or reversed directions to achieve turning.

  • Backward: Both motor groups reverse — car moves straight back

  • Right: Left motors run faster / right motors slow down or reverse — car turns right
  • Center (released): Dead zone detected — all motors stop

// Safety

Wireless Fail-Safe

⚠ Wireless Fail-Safe

If the car ESP32 does not receive a control packet for approximately 300 milliseconds, it automatically sets all motor outputs to zero, stopping the car immediately.


This software-level fail-safe is built into the car's firmware. It prevents the car from continuing to drive uncontrolled if the Wi-Fi connection drops, the controller is switched off, or the wireless link is interrupted for any reason. This is a DIY project feature, not a certified safety system.

// For Everyone

Simple Explanations

What is ESP32?

The ESP32 is a small, low-cost microcontroller with built-in Wi-Fi and Bluetooth. It can read sensors, control motors, and communicate wirelessly — making it ideal for DIY electronics projects like this RC car.

What is an L298N?

The L298N is a motor driver chip. A microcontroller cannot supply enough current to drive DC motors directly. The L298N acts as an amplifier — it takes low-current signals from the ESP32 and uses them to control much higher motor currents.

What is a joystick module?

A joystick module is a small thumbstick that outputs two analog voltage values — one for the X axis (left/right) and one for the Y axis (forward/backward). The ESP32 reads these values and converts them into motor commands.

How does Wi-Fi control work?

The controller ESP32 creates a Wi-Fi network. The car ESP32 connects to it. The controller continuously sends small data packets over UDP containing the joystick position. The car receives the packets and drives its motors accordingly.

How does differential steering work?

Instead of a physical steering axle, this car turns by running the left and right motor groups at different speeds. To turn left, the right motors spin faster than the left. To turn right, the left motors spin faster. Sharp turns can even reverse one side.

What happens if Wi-Fi disconnects?

If the car does not receive a control packet for about 300 milliseconds, the firmware automatically stops all four motors. This prevents the car from continuing to move uncontrolled if the wireless connection is interrupted.
